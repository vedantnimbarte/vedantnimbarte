### About me

I'm obsessed with the surface between **humans and machines** — terminals, editors, and the AI agents that increasingly live inside them. I build the tools I wish existed, and I like going all the way down: I have built a kernel, a browser engine and an LLM inference engine to understand how they really work.

- **Currently building** → a multi-provider coding agent, a desktop dev workspace, and a bare-metal microkernel
- **Currently learning** → Rust internals, GPU runtimes, distributed agent orchestration
- **Open to** → collaborating on developer tools, AI infra, and systems projects
